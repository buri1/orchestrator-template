## Overview

OpenMAIC (Open Multi-Agent Interactive Classroom) is a Tsinghua University research project that creates immersive multi-agent learning environments. Multiple AI agents take on different roles — teachers, students, tutors — and interact in a simulated classroom setting. The system orchestrates these agents to create educational experiences.

The TypeScript implementation provides a web interface for one-click deployment of multi-agent classroom simulations. With 11K stars, it has significant interest in the AI education space.

---

## What's Valuable for Us

- **Multi-agent role assignment patterns**: How they assign and enforce different agent roles
- **Agent interaction protocols**: Communication patterns between agents in different roles
- **TypeScript orchestration**: Their approach to coordinating multiple agents in TypeScript

## What's NOT Relevant

- **Education domain**: We're building software development orchestration, not classrooms
- **AGPL license**: Restrictive for commercial use
- **Simulation focus**: We need production agent coordination, not simulated interactions

## Summary

The cmux.com product page describes cmux as a native macOS terminal application built on Ghostty, designed for developers running multiple AI coding agents simultaneously. Key features include vertical tabs displaying git branches/working directories/notifications, notification rings for attention management, split panes, an embedded scriptable browser, a socket API for automation, and GPU acceleration via libghostty.

The page is available in German (cmux.dev/de redirects to cmux.com/de) and emphasizes the "replace tmux without any configuration" value proposition. Built with Swift + AppKit (not Electron), it's free and open-source.

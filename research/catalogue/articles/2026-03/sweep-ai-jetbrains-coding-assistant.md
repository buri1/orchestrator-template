## Summary

Sweep is a JetBrains IDE plugin that provides AI-powered coding assistance including autocomplete, code review, web search, and codebase intelligence. It uses proprietary language models for speed and security, with zero third-party data retention. The plugin supports all major JetBrains IDEs and has achieved strong market traction with 40K+ installs and a 4.9-star rating, making it the #1 AI plugin in the JetBrains Marketplace.

Notable enterprise customers include Ramp, Amplitude, Atlassian, and Klook. The product differentiates on speed (millisecond autocomplete), privacy (custom models, no data retention), and deep IDE integration (full project indexing).

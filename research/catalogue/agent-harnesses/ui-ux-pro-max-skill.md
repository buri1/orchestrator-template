## Overview

UI/UX Pro Max Skill is an agent skill that provides design intelligence for building professional user interfaces. It works across multiple coding agent platforms including Claude Code, Codex CLI, Cursor AI, Kiro, and Windsurf AI. The skill injects design principles, component patterns, and platform-specific guidelines into the agent's context to improve the quality of generated UIs.

The skill covers mobile UI, landing pages, React components, and Tailwind CSS patterns. It's the most starred UI-focused agent skill on GitHub, indicating strong community validation of the approach.

With nearly 48K stars, it validates the pattern of codifying domain expertise as reusable agent skills — the same pattern our catalogue's ADOPTABLE-PATTERNS backlog tracks.

## Technical Architecture

- **Skill format**: Compatible with Claude Code skills, Codex skills, and other agent harness skill systems
- **Design system**: Built-in knowledge of responsive design, mobile-first patterns, Tailwind utilities
- **Platform support**: Claude Code, Codex CLI, Cursor AI, Kiro, Windsurf AI, Copilot, Trae, Qoder
- **Output**: Generates React + Tailwind CSS components following design best practices
